# Blockfall

Fallende-Blöcke-Puzzle im Browser, optimiert für das iPhone im Hochformat und auch per Tastatur spielbar. Reines HTML/CSS/JavaScript, ohne Abhängigkeiten und ohne Build-Schritt. Installierbar als Web-App und offline spielbar (über https oder `localhost`).

## Starten

```
node serve.js        # optional Port als Argument, Standard 8080
```

Dann im Browser `http://localhost:8080` öffnen. Der Server zeigt beim Start auch die Adresse im lokalen Netz an.
